
# Capstone 1: Business Analysis with SQL and Excel

A sales territory analysis for **EmporiUm**, a fictional student bookstore chain that also sells technology, art supplies, and other products in stores and online. This capstone uses SQL to answer sales manager questions and Excel to turn selected results into a PivotChart.


## Project goals

- Use SQL to prepare a sales territory report and answer the assigned manager questions.
- Export results for a selected analysis question and visualize them in an Excel PivotChart.
- Explain the findings in a short video walkthrough and live presentation.

## Territory and questions

- **Assigned sales territory:** MAINE
  
## Tools

- SQL for data querying and report generation
- Microsoft Excel for analysis and PivotChart visualization

## About the data

The project uses sample data for the fictional EmporiUm business. The analysis is for an assigned sales territory and is intended for educational purposes.
